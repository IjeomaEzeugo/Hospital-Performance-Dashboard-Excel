# Nigerian Hospital Performance Dashboard (Excel)

## Project Overview

This project analyses a hospital dataset in Microsoft Excel to demonstrate how spreadsheet tools can be used to explore patient activity, treatment outcomes, treatment costs, and length of stay. It includes a hospital dataset, PivotTable summaries, business questions, and an Excel dashboard.

## Business Questions

The analysis is designed to help answer questions such as:

1. How many patient records are included in the dataset?
2. How many patients recovered, were referred, remained under treatment, or were deceased?
3. What is the total treatment cost recorded?
4. What is the average length of stay?
5. Which diagnoses account for the largest number of patient records?
6. How do patient records vary by admission month, ward, gender, and insurance status?

## Workbook Contents

| Worksheet | Description |
|---|---|
| `OUTLINE` | Project workflow and skills covered |
| `Hospitaldataset` | 500 patient records with 19 fields |
| `PIVOT` | PivotTable summaries used for analysis |
| `QUESTION` | Business questions and corresponding KPI ideas |
| `DASHBOARD` | Dashboard visualisations embedded in the workbook |

## Dataset Fields

The dataset contains fields relating to:

- Patient ID, gender, date of birth, and age
- Ward, blood pressure, doctor, and diagnosis
- Admission date and discharge date
- Treatment cost and insurance status
- Patient outcome and admission month
- Recovered, deceased, referred, and ongoing-treatment counts
- Length of stay

## How to Use

1. Download `HOSPITAL PROJECT.xlsx` from this repository.
2. Open the workbook in Microsoft Excel.
3. Review the `Hospitaldataset` worksheet to understand the source fields.
4. Explore the `PIVOT` worksheet for summary tables.
5. Open the `DASHBOARD` worksheet to view the visualisations.
6. Use the `QUESTION` worksheet to review the business questions addressed by the project.

## Important Data Note

Before making this repository public, confirm that the dataset is entirely synthetic or has been properly de-identified and that you have permission to publish it. Do not publish real patient or confidential hospital information. Patient IDs alone do not guarantee that a dataset is anonymous.

If the dataset is synthetic, state that clearly here and in the repository description. If it is based on real records, remove or safely transform identifying and sensitive fields before publication, in accordance with the relevant permissions and privacy requirements.

## Limitations

- The results describe only the records included in this workbook.
- The dataset covers admission dates from January to July 2026.
- The figures should not be interpreted as representative of all Nigerian hospitals.
- This is a descriptive Excel analytics project; it does not establish causation or provide clinical recommendations.
